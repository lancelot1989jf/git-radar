## 强制约束（最高优先级）

- 默认模式：只读。未获得用户明确确认前，禁止任何会修改文件或 Git 状态的操作。
- 必须先确认再执行：任何写操作（包括但不限于编辑文件、apply_patch、重命名、删除、生成代码、格式化、安装依赖导致锁文件变化）。
- 严禁自动提交：禁止执行 `git add`、`git commit`、`git push`、`git rebase`、`git merge`，除非用户在当前对话中明确授权。
- 每次任务先输出“执行计划 + 将要运行的命令（只读/写入标记）”，等待用户确认后再执行写入类命令。
- 若误触发写操作，必须立即停止，并先报告受影响文件与命令，等待用户指示。
